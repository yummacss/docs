## Use Props

Try a prop first: the component applies it itself.

```tsx
<Badge tone="subtle" color="green" size="lg" shape="pill">
  Shipped
</Badge>
```

Every component page lists its props. Most of what people reach for `className` to do already exists as one.

## className

Every component takes `className` & merges it into its own classes.

```tsx
<Button className="w:100%">Save</Button>
```

It adds what the component does not set, like the width above, and overrides what it does.

```tsx
<Button className="c:accent">Save</Button>
```

Components pass your classes through [`merge`](/docs/class-merge), which drops the class yours replaces, so `c:accent` wins over the component's `c:white`.

<Hint icon="info">
  A prop still beats `className`: it is checked, and it survives an edit to
  the component's own classes.
</Hint>

## The Focus Outline

Every component draws a focus outline, and one `focus` prop styles it.

```tsx
<Dialog trigger="Rename" title="Rename file" focus="fv:oc:blue-2/60" />
```

Pass `fv:oc:*` for the color, `fv:ow:*` for the thickness & `fv:oo:*` for the offset. Unlike `className`, which reaches only the root, `focus` reaches every focusable part, such as all four buttons of a Dialog.

`focus={false}` removes the outline & its danger, error & success tints.

```tsx
<Button variant="danger" focus={false} className="fv:bg:silver-2">
  Delete
</Button>
```

<Hint icon="warning">
  `focus={false}` alone leaves nothing marking where the keyboard is, which
  fails WCAG 2.4.7. Put something back.
</Hint>

## Own Your Components

When props & `className` are not enough, edit the file. `yummaui add` copies it into your project & nothing overwrites it later.

The primitive underneath is documented by [Base UI](https://base-ui.com). To remove a component you no longer use, run [`yummaui prune`](/components/cli#remove-unused-components).

## Colors & Theme

Colors come from Yumma CSS, so you change them in `yumma.config.mjs`. See [Color System](/docs/color-system) & [Configuration](/docs/configuration).
