## Define Keyframes

Name an animation once in `theme.keyframes` & write its body as plain CSS. Each name becomes an `an:` class.

```mjs title="yumma.config.mjs" mark={5-8}
import { defineConfig } from "yummacss";

export default defineConfig({
  theme: {
    keyframes: {
      spin: "to { rotate: 360deg; }",
      "fade-in": "from { opacity: 0; }",
    },
  },
});
```

## Use Keyframes

Combine a name with [Animation Duration](/docs/animation-duration), [Animation Timing Function](/docs/animation-timing-function) & [Animation Iteration Count](/docs/animation-iteration-count).

<CodeGroup>

```tsx title="page.tsx" "an:spin"
<span className="d:b w:4 h:4 bw:2 br:9999 an:spin adu:700 atf:l aic:inf"></span>
```

```css title="output.css"
.an\:spin {
  animation-name: spin;
}

@keyframes spin {
  to { rotate: 360deg; }
}
```

</CodeGroup>

Only the keyframes a class uses are written to the output, once, however many variants use them.

## Reduced Motion

Stop an animation for people who have asked for less motion with the [`@prm:`](/docs/media-queries#reduced-motion) variant.

```tsx "@prm:an:none"
<span className="an:spin adu:700 aic:inf @prm:an:none"></span>
```
