## Install the CLI

Yumma CSS includes the Yumma CLI, which generates production-ready styles.

```bash
pnpm add yummacss -D
```

## Set Up

Initialize a configuration file in your project.

```bash
pnpm dlx yummacss init
```

Creates `yumma.config.mjs` at your project root, read by the CLI & both plugins.

```mjs title="yumma.config.mjs" mark={4-5}
import { defineConfig } from "yummacss";

export default defineConfig({
  source: ["./src/**/*.{js,jsx,ts,tsx,mdx,html}"],
  output: "./src/styles.css",
});
```

### Source

The files to scan for classes.

<Note>
  Use glob patterns to include subfolders & specific file types.
</Note>

```mjs title="yumma.config.mjs" mark={4}
import { defineConfig } from "yummacss";

export default defineConfig({
  source: ["./src/**/*.html"],
});
```

### Output

Specifies the output path for the compiled CSS file.

<Note>
  Only the CLI uses `output`. The bundler plugins ignore it & inject the
  generated CSS through the `@yummacss;` marker instead.
</Note>

```mjs title="yumma.config.mjs" mark={4}
import { defineConfig } from "yummacss";

export default defineConfig({
  output: "./src/styles.css",
});
```

### Normalize

Determines whether to include base styles normalization.

```mjs title="yumma.config.mjs" mark={4}
import { defineConfig } from "yummacss";

export default defineConfig({
  normalize: true, // default: true
});
```

### Theme

Extends or overrides default design tokens.

#### Colors

Add color families. Each gets shades `1` to `12` unless you write them out.

<Note>
  Use `percentage` to control how much the shade is lightened or darkened.
</Note>

```mjs title="yumma.config.mjs" mark={4-12}
import { defineConfig } from "yummacss";

export default defineConfig({
  theme: {
    colors: {
      brand: "#9333EA",
      percentage: {
        light: 14,
        dark: 14,
      },
    },
  },
});
```

A color can be a light & dark pair, and so is every shade of it. See [Dark Mode](/docs/dark-mode).

```mjs title="yumma.config.mjs" mark={6}
import { defineConfig } from "yummacss";

export default defineConfig({
  theme: {
    colors: {
      surface: { light: "#ffffff", dark: "#111214" },
    },
  },
});
```

<Note>
  One paired color sets `color-scheme: light dark` on `:root`, so the page
  follows the system. [Color Scheme](/docs/color-scheme) overrides it.
</Note>

#### Screens

Define custom media query breakpoints or override existing ones.

```mjs title="yumma.config.mjs" mark={4-13}
import { defineConfig } from "yummacss";

export default defineConfig({
  theme: {
    screens: {
      sm: "40rem",
      md: "48rem",
      lg: "64rem",
      xl: "80rem",
      xxl: "96rem",
      "3xl": "112rem",
    },
  },
});
```

#### States

Name your own variants for attributes your components set. Each name becomes a prefix like `h:`. See [States](/docs/states).

```mjs title="yumma.config.mjs" mark={4-7}
import { defineConfig } from "yummacss";

export default defineConfig({
  theme: {
    states: {
      closing: "[data-ending-style]",
    },
  },
});
```

#### Fonts

Add font stacks, each an `ff:` class. See [Font Family](/docs/font-family).

```mjs title="yumma.config.mjs" mark={4-7}
import { defineConfig } from "yummacss";

export default defineConfig({
  theme: {
    fonts: {
      display: '"Esteban", serif',
    },
  },
});
```

#### Keyframes

Add keyframes, each an `an:` class. See [Animation Name](/docs/animation-name).

```mjs title="yumma.config.mjs" mark={4-7}
import { defineConfig } from "yummacss";

export default defineConfig({
  theme: {
    keyframes: {
      spin: "to { rotate: 360deg; }",
    },
  },
});
```

#### Easings

Add easing curves, each a `ttf:` & an `atf:` class. See [Transition Timing Function](/docs/transition-timing-function).

```mjs title="yumma.config.mjs" mark={4-7}
import { defineConfig } from "yummacss";

export default defineConfig({
  theme: {
    easings: {
      "out-quart": "cubic-bezier(0.25, 1, 0.5, 1)",
    },
  },
});
```

### Safelist

Classes to generate even when no file contains them, such as one built at runtime.

<Note>
  The scanner cannot see a class built at runtime, such as
  `` `d:${display}` ``, so list it here.
</Note>

```mjs title="yumma.config.mjs" mark={4}
import { defineConfig } from "yummacss";

export default defineConfig({
  safelist: ["bg:red", "c:white", "fw:700"],
});
```

## Generate Styles

The CLI scans files specified in `source` & generates a CSS file based on the utilities used.

### HTML Input

```tsx title="index.tsx"
<button className="bg:white c:black bw:1">Button</button>
```

### CSS Output

Running the `build` or `watch` command generates the following CSS:

```css title="styles.css"
.bg\:white {
  background-color: #ffffff;
}

.bw\:1 {
  border-width: 1px;
}

.c\:black {
  color: #000000;
}
```

## CLI Commands

The Yumma CSS CLI provides commands to manage your project.

<Note>
  Create a `yumma.config.mjs` file before running these commands. If there is
  none, run `yummacss init`.
</Note>

### Build

Compile your Yumma CSS files once.

```bash
pnpm dlx yummacss build
```

### Watch

Watch for file changes & recompile automatically.

```bash
pnpm dlx yummacss watch
```
