## Usage

```html title="index.html" mark={4}
<!doctype html>
<html>
  <head>
    <script src="https://unpkg.com/@yummacss/runtime"></script>
  </head>
  <body>
    <div class="c-indigo fw-500">Hello World</div>
  </body>
</html>
```

There is nothing else to set up. No config file, no marker in a stylesheet, no install step.

## When To Use It

You can use this for a single HTML file, a CodePen, or anything static where a build pipeline would be more trouble than it's worth, or if you just want to try things out, create quick design prototypes and test new ideas.
