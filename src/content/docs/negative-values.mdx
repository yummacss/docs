## Using Negative Values

Put a minus sign in front of the value, after the colon: `ml:-4` is a margin of `-1rem`.

Only properties CSS lets go negative take one, such as margins, positioning, `z-index` & transforms. `p:-4` & `w:-4` produce nothing.

## Margin

Every margin utility takes a negative value, to overlap elements.

```tsx "ml:-4"
<div className="zi:10 …">A</div>
<div className="ml:-4 zi:20 …">B</div>
<div className="ml:-4 zi:30 …">C</div>
```

## Positioning

`t:`, `r:`, `b:`, `l:` & `i:` take a negative value, to place an element outside its parent.

```tsx "t:-4" "l:-4"
<div className="p:r …">
  <div className="p:a t:-4 l:-4 …"></div>
</div>
```

## Z-Index

Negative z-index values allow you to place elements behind their siblings or parents. Use `zi:-(value)` to target negative stack levels.

```tsx "zi:-10"
<div className="p:r …">
  <div className="p:a zi:-10 …"></div>
  <span>Background Layer</span>
</div>
```

## Sign Toggle

The minus sign flips the sign of the utility's value, which matters for utilities whose value is already negative.

### Letter Spacing

`ls:1` & `ls:2` are already negative, so `ls:-1` & `ls:-2` flip them to wider spacing.

| Class  | Standard Value | Negated Class | Negated Value |
| ------ | -------------- | ------------- | ------------- |
| `ls:0` | `0`            | `ls:-0`       | `0`           |
| `ls:1` | `-0.05 em`     | `ls:-1`       | `0.05 em`     |
| `ls:2` | `-0.025 em`    | `ls:-2`       | `0.025 em`    |
| `ls:3` | `0.025 em`     | `ls:-3`       | `-0.025 em`   |
| `ls:4` | `0.05 em`      | `ls:-4`       | `-0.05 em`    |
| `ls:5` | `0.1 em`       | `ls:-5`       | `-0.1 em`     |

<Note>
  Sign-toggle behavior applies to any utility where the defined CSS value
  already starts with a negative number.
</Note>

```tsx "ls:1" "ls:-1"
<p className="ls:1 …">Standard (Tight)</p>
<p className="ls:-1 …">Negated (Wide)</p>
```
