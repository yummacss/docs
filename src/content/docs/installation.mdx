## Why Yumma CSS?

- **Classes read as the CSS they write.** A class is the initials of a property & its value: `d:f` is `display: flex`, `jc:sb` is `justify-content: space-between`. Knowing CSS, you already know most of the names. See [Naming Convention](/docs/naming-convention).
- **One scale for every value.** Spacing & sizing move in steps of 0.25rem & every color has twelve shades, so a layout stays consistent without a token file. A value off the scale is a CSS function, such as `w:var(--width)`. See [CSS Functions](/docs/css-functions).
- **Only what you use.** The build scans your files & writes only the classes it finds.
- **A reset that steps aside.** No rule in the reset weighs more than one class, so a utility always wins over it. See [Normalization](/docs/normalize).
- **Your theme in one file.** Colors with light & dark values, breakpoints, fonts, states, easings & keyframes live in `yumma.config.mjs`. See [Configuration](/docs/configuration).
- **Checked, by you or your agent.** `yummacss lint` names every class that does not exist & the closest one that does, & [Coding Agents](/docs/agents) teaches an agent the same rules.
- **Components when you want them.** [Yumma UI](https://www.yummaui.com/components/installation) is a set of accessible React components written in these classes, copied into your project to edit.

## Set Up a Framework

Add Yumma CSS to your framework of choice with a single plugin.

### Use with Vite

Use the `@yummacss/vite` plugin with Vite & Vite-based frameworks like SvelteKit, Astro, Nuxt, & Solid. Generated CSS is rebuilt automatically as you work.

<Stepper>
  <Step title="Install Yumma CSS">
    ```bash
    pnpm add yummacss @yummacss/vite -D
    ```
  </Step>

  <Step title="Add the Plugin">
    Register the plugin in your Vite configuration.

    ```ts title="vite.config.ts" mark={2,5}
    import { defineConfig } from "vite";
    import yummacss from "@yummacss/vite";

    export default defineConfig({
      plugins: [yummacss()],
    });
    ```

  </Step>

  <Step title="Configure Sources">
    Specify the locations/paths of your project files in the config file.

    ```mjs title="yumma.config.mjs" mark={4}
    import { defineConfig } from "yummacss";

    export default defineConfig({
      source: ["./src/**/*.{ts,tsx}"],
    });
    ```

  </Step>

  <Step title="Add the Marker">
    Add the `@yummacss;` marker to your CSS entry file. The plugin replaces it with generated CSS.

    ```css title="src/styles.css"
    @yummacss;
    ```

  </Step>
</Stepper>

### Use with Next.js

Use the `@yummacss/postcss` plugin with Next.js. It works with both Turbopack & Webpack through the built-in PostCSS support.

<Stepper>
  <Step title="Install Yumma CSS">
    ```bash
    pnpm add yummacss @yummacss/postcss -D
    ```
  </Step>

  <Step title="Configure PostCSS">
    Register the plugin in your PostCSS configuration.

    ```mjs title="postcss.config.mjs" mark={3}
    export default {
      plugins: {
        "@yummacss/postcss": {},
      },
    };
    ```

  </Step>

  <Step title="Configure Sources">
    Specify the locations/paths of your project files in the config file.

    ```mjs title="yumma.config.mjs" mark={4}
    import { defineConfig } from "yummacss";

    export default defineConfig({
      source: ["./src/**/*.{ts,tsx}"],
    });
    ```

  </Step>

  <Step title="Add the Marker">
    Add the `@yummacss;` marker to your global CSS file. The plugin replaces it with generated CSS.

    ```css title="globals.css"
    @yummacss;
    ```

  </Step>
</Stepper>

<Hint icon="info">
  The PostCSS plugin works anywhere PostCSS runs, not only Next.js.
</Hint>

## Set Up Standalone

Yumma CSS can be used on its own, without a framework.

### Use with CLI

Prefer generating a plain CSS file? Install Yumma CSS with your favorite package manager & use the CLI:

<Stepper>
  <Step title="Install Yumma CSS">
    ```bash
    pnpm add yummacss -D
    ```
  </Step>

  <Step title="Initialize Configuration">
    Create a configuration file in your project.

    ```bash
    pnpm dlx yummacss init
    ```

  </Step>

  <Step title="Configure Sources">
    Specify the locations/paths of your project files in the config file.

    ```mjs title="yumma.config.mjs" mark={4-5}
    import { defineConfig } from "yummacss";

    export default defineConfig({
      source: ["./src/**/*.{ts,tsx}"],
      output: "./src/styles.css",
    });
    ```

  </Step>

  <Step title="Build styles">
    Start using Yumma CSS classes, then generate your styles.

    ```bash
    pnpm dlx yummacss build
    ```

  </Step>
</Stepper>
