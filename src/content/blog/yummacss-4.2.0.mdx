Animate an element in & out, name the variants your components need, & size things by their container, all without writing CSS by hand.

## Starting Style

An element that appears has no previous style to transition from. The [`@st:`](/docs/starting-style) variant gives it one, so an enter animation is just classes.

<CodeGroup>
```tsx title="page.tsx" "@st:o:0" "@st:s:90"
<div className="tp:a tdu:150 ttf:eo @st:o:0 @st:s:90">Saved to Documents</div>
```

```css title="output.css"
@starting-style {
  .\@st\:o\:0 {
    opacity: 0;
  }
  .\@st\:s\:90 {
    scale: .9;
  }
}
```
</CodeGroup>

It is an at-rule like a breakpoint, so `@md:@st:o:0` works too.

## Your Own States

Components mark what they are doing with attributes. A details element is `[open]`, & a Base UI popup is `[data-ending-style]` while it closes. Name the attribute once in `theme.states` & it becomes a variant like `h:`.

<CodeGroup>
```mjs title="yumma.config.mjs" mark={5-8}
import { defineConfig } from "yummacss";

export default defineConfig({
  theme: {
    states: {
      closing: "[data-ending-style]",
      open: "[open]",
    },
  },
});
```

```tsx title="page.tsx" "closing:o:0"
<div className="tp:o tdu:150 closing:o:0">Rename file</div>
```

```css title="output.css"
.closing\:o\:0[data-ending-style] {
  opacity: 0;
}
```
</CodeGroup>

`@st:` covers the way in & a state covers the way out, which together animate a popup both ways. Nothing is built in: every state is one you name. See [States](/docs/states).

## Keyframes & Fonts

`theme.keyframes` takes the body of a `@keyframes` rule, & each name becomes an `an:` class. The rest of the animation is utilities too: `adu:` for duration, `ad:` for delay, `atf:` for timing & `aic:` for how many times it runs.

<CodeGroup>
```mjs title="yumma.config.mjs" mark={5-7}
import { defineConfig } from "yummacss";

export default defineConfig({
  theme: {
    keyframes: {
      spin: "to { rotate: 360deg; }",
    },
  },
});
```

```tsx title="page.tsx" "an:spin"
<span className="d:b w:4 h:4 bw:2 br:9999 an:spin adu:700 atf:l aic:inf"></span>
```
</CodeGroup>

`theme.fonts` does the same for `ff:`, so a display face is a class like any other. A name that matches a built-in family replaces it.

```mjs title="yumma.config.mjs" mark={5-7}
import { defineConfig } from "yummacss";

export default defineConfig({
  theme: {
    fonts: {
      display: '"Esteban", serif',
    },
  },
});
```

## Container Queries

Mark the parent with `ct:is`, then prefix a child's class with `@c:` & a breakpoint name. The class applies once the container, not the window, reaches that width.

<CodeGroup>
```tsx title="page.tsx" "ct:is" "@c:sm:fs:xl"
<div className="ct:is">
  <h2 className="fs:md @c:sm:fs:xl">Recent files</h2>
</div>
```

```css title="output.css"
.ct\:is {
  container-type: inline-size;
}

@container (min-width: 40rem) {
  .\@c\:sm\:fs\:xl {
    font-size: 1.25rem;
  }
}
```
</CodeGroup>

The same card can sit in a narrow sidebar & a wide page & lay itself out for each. See [Container Queries](/docs/container-queries).

## CSS Functions

A value no scale holds, such as the viewport minus a header, is written as the function it is. `calc()`, `clamp()`, `min()` & `max()` work in any utility that takes a length, & `var()` works in every utility.

<CodeGroup>
```tsx title="page.tsx" "max-h:calc(100dvh-5rem)"
<nav className="p:st t:20 max-h:calc(100dvh-5rem)"></nav>
```

```css title="output.css"
.max-h\:calc\(100dvh-5rem\) {
  max-height: calc(100dvh - 5rem);
}
```
</CodeGroup>

A class cannot hold spaces, so write the function without them. The spaces CSS needs around `+` & `-` are added in the output. See [CSS Functions](/docs/css-functions).

## Smaller Changes

`tp:t` transitions `translate`, `scale` & `rotate` along with `transform`, so the individual transform properties animate with it.

Stacked at-rule variants keep both queries. `@sm:@lg:` used to lose one of them.

Form controls inherit the whole font from the page, not only its family.

The full list is in the [changelog](https://github.com/yummacss/yummacss/blob/main/CHANGELOG.md).
